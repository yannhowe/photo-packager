2. Package format

The photo layout and box are sized together. Each preset starts with recommended paper, spacing, and cover text.

3. Output sheet

Epson/AirPrint mode pre-rotates the metadata page 180° to cancel the opposite-edge flip produced by the L6170. It will look upside down in the PDF but print upright behind the photo.

Portrait files use a portrait print frame; landscape files use a landscape frame. The metadata top edge follows the image top edge.

After a test print, use these corrections only for a consistent printer feed offset. Positive values move metadata right or down.

4. Metadata backs

GPS is opt-in and processed locally. Coordinates are never sent to a map or geocoding service.
